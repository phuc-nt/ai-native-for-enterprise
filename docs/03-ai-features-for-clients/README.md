# AI Features for Clients

Nhóm tài liệu cho **mục tiêu 2**: đề xuất, tư vấn, thiết kế tính năng AI cho sản phẩm và hệ thống của khách hàng. Toàn bộ đang là file giữ chỗ, mỗi file ghi vai trò và nguồn có sẵn để rút. Thứ tự đọc toàn bộ `docs/` ở [docs/README.md](../README.md).

Nền đã có sẵn ở nơi khác, không viết lại ở đây: khung kiến trúc và nghiệm thu cho agent chạy trên dữ liệu thật ở [nhóm 01](../01-ai-ready-enterprise/README.md); nguyên tắc và bằng chứng ở [nhóm 00](../00-foundations/README.md). Nhóm này chỉ bổ sung phần **phương pháp tư vấn** và **tri thức để ghép nhanh giải pháp vào bối cảnh khách**.
