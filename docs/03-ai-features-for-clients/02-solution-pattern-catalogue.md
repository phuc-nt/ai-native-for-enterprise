# Solution Pattern Catalogue

> **Chưa viết.** File giữ chỗ, tạo 2026-09-07.
>
> **Phục vụ:** mục tiêu 2.
> **Người đọc:** người ghép giải pháp vào bối cảnh khách trong buổi đầu; người viết proposal cần kiến trúc tham chiếu.
> **Trả lời:** mỗi mẫu một mục cùng khung: bài toán hợp và không hợp, kiến trúc một hình, dữ liệu cần có ở lớp nào của bậc thang, giao diện cho agent, chi phí và độ trễ đo được, rủi ro và cách giảm, sản phẩm đã chứng minh. Danh sách khởi đầu từ portfolio: RAG có trích dẫn on-device (my-notebook); chat với database qua semantic layer chỉ đọc (my-db-mate); multi-agent với action gateway (my-crew); xử lý tài liệu và bản vẽ bằng vision LLM (scan-to-ebook); agent nền 24/7 trên dữ liệu người dùng (case study coach); memory cho agent (my-kioku); quản trị fleet agent (my-dandori); tích hợp Jira/Confluence/Slack qua MCP.
